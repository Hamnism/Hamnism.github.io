## 1.2 (11)

### 新機能

- **返信を 💬 アイコンで表示。**タップするとその返信ツリーをまとめて読めます。
- **Live モードの大きな画像をタップ**すると、「画像を開く / 返信ツリー / この ID を抽出」を選べるメニューが出るようになりました。
- **書き込みメニューに「端末情報を挿入」を追加。**機種名・OS・アプリのバージョンをワンタップで本文に入れられます。
- **ID の表示を [4/20] 形式に。**その ID が何回投稿しているうちの何回目かが一目で分かります。

### 改善

- **スレッドの読み込みを高速化。**特にお気に入りや履歴から開くときが速くなりました。
- **スクロール時の動作を軽く。**引っかかりと発熱を抑えました。
- **広告に画像が表示されるように。**あわせて最新レス位置の広告は控えめなバナーにし、初回スクロールで表示されない不具合も修正しました。
- 設定画面の説明をより分かりやすく整理しました。
