iPhoneで5ch（5ちゃんねる）を読む方法は、**Safariや通常のブラウザで5chのサイトを開く**か、**専ブラ（掲示板専用ブラウザ）を使う**かの2つです。

たまに読むだけならSafariなどで十分です。毎日のように読む人や、書き込みもしたい人には、続きから読める、見たくないレスを隠せる、複数のスレを行き来できる、といった機能がそろった専ブラが便利です。

この記事では、それぞれの始め方と、SafariをはじめとしたWebブラウザアプリと専ブラの違いを紹介します。

## iPhoneで5chを読む方法は？

iPhoneで5chを読む方法は、大きく分けて次の2つです。

| 方法 | 向いている人 |
|---|---|
| Webブラウザアプリで5chのサイトを開く | アプリを入れずに、たまに読みたい人 |
| 専ブラ（掲示板専用ブラウザ）を使う | ・快適に掲示板を閲覧したい人<br>・毎日読む人<br>・書き込みもしたい人<br>・いくつものスレを追いかけたい人<br>・実況など流れの早いスレを追いたい人 |

どちらも、5chのスレを読めることに変わりはありません。違うのは、読みやすさと、便利な機能があるかどうかです。

## Webブラウザアプリで5chを読むには？

アプリを入れなくても、Safariで5chのサイトを開けば読めます。

1. Safariで、5ちゃんねるのサイト（5ch.io）を開きます
2. 読みたい板を選びます
3. スレ一覧から、読みたいスレをタップします

よく見る板は、Safariのブックマークや、共有メニューの「ホーム画面に追加」で登録しておくと、すぐに開けます。

## 専ブラとは？

専ブラは「掲示板専用ブラウザ」の略で、5chのような掲示板を読み書きするためのアプリです。

Safariのようなふつうのブラウザは、どんなWebページでも開けるように作られています。専ブラは掲示板だけに絞って作られているので、スレを読む・追いかける・書き込むといった操作が、掲示板に合わせて使いやすくなっています。

多くの専ブラは、5chだけでなく、ほかの掲示板にも対応しています。

## Safariと専ブラは何が違う？

おもな違いは、次のとおりです。

| | Safari | 専ブラ |
|---|---|---|
| インストール | 不要 | アプリを入れる |
| どこまで読んだか | 自分で探す | どこまで読んだかを記憶し、続きから読める |
| 複数のスレ | Safariのタブで開く | アプリの中のタブで行き来できる |
| 見たくないレス | そのまま表示される | NG機能で隠せる |
| アンカー（>>1など） | リンクで移動する | ポップアップで、その場で確認できる |
| 画像 | リンクを開いて見る | サムネイルで並び、まとめて見られる |
| 書き込み | サイトのフォームから | アプリの書き込み画面から。名前や履歴も覚えてくれる |
| 新着の確認 | 自分で開き直す | 引っ張って更新。アプリによっては通知も |

### 続きから読める

長いスレを読んでいると、どこまで読んだか分からなくなりがちです。専ブラは読んだ位置を覚えているので、スレを開き直すと続きから読めます。新しく付いたレスも、ひと目で分かります。

Lichenでの使い方は、{{< post "F05" "続きから読む・更新の記事" >}}で紹介しています。

### 見たくないレスを隠せる

掲示板には、荒らしや、自分が見たくない話題も流れてきます。専ブラのNG機能を使えば、特定のIDや言葉を含むレスを隠せます。

Lichenでの使い方は、{{< post "F14" "NG機能の記事" >}}で紹介しています。

### アンカーをポップアップで確認できる

「>>1」のようなアンカーをタップすると、専ブラでは相手のレスがポップアップで表示されます。読んでいる場所から離れずに、会話の流れを追えます。

## Safariと専ブラ、どちらを選べばいい？

使い方に合わせて選ぶのがおすすめです。

- **たまにまとめを見て、気になったスレだけ読む** → Safariで十分です
- **毎日決まった板やスレを追いかけている** → 続きから読める専ブラが便利です
- **書き込みもしたい** → 名前や書き込みの履歴を覚えてくれる専ブラが楽です
- **荒れたスレでも快適に読みたい** → NG機能のある専ブラが向いています

まずはSafariで読んでみて、「もっと読みやすくしたい」と感じたら専ブラを試してみる、という順番でも問題ありません。

## 専ブラで5chを読むには？

ここでは、掲示板専用ブラウザ「Lichen（ライケン）」を例に、読み始めるまでの流れを紹介します。Lichenは、iPhoneとiPadのための、広告のない5ch専ブラです。

1. App StoreからLichenをインストールします
2. Homeの上にある「New Tab」をタップすると、サイトと板を選ぶ「Sites」画面が開きます
3. サイト名の列から「5ちゃんねる」を選び、カテゴリから読みたい板をタップします
4. スレ一覧から、読みたいスレをタップします

はじめて使うときの画面の見方は、{{< post "F01" "はじめてのLichen" >}}で紹介しています。板の選び方は、{{< post "F02" "Sitesの記事" >}}でくわしく紹介しています。

Lichenには、Homeにいろいろな板の勢いのあるスレが流れてくる「Discovery」もあるので、板を選ばなくても、盛り上がっているスレからすぐに読み始められます。

## よくある質問

**Q. Safariで読むのと専ブラで読むのとで、読めるスレは変わりますか？**
A. 変わりません。どちらも同じ5chのスレを読んでいます。違うのは、読みやすさと使える機能です。

**Q. 専ブラで5ch以外の掲示板も読めますか？**
A. 専ブラによって違います。Lichenは、5ちゃんねるのほかに、エッヂ、まちBBS、おーぷん2ちゃんねる、したらばなどにも対応しています。対応している掲示板の一覧は、{{< post "F35" "対応している掲示板" >}}で確認できます。

**Q. 専ブラから書き込みもできますか？**
A. 多くの専ブラは書き込みに対応しています。Lichenでの書き込み方は、{{< post "F09" "書き込みの基本" >}}で紹介しています。

**Q. iPadでも専ブラは使えますか？**
A. 使えます。Lichenは、iPadではスレ一覧とスレを並べて表示する2カラム表示になり、広い画面を活かして読めます。くわしくは{{< post "F44" "iPadと横向きの記事" >}}で紹介しています。
