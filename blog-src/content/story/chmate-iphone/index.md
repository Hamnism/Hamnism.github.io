ChMateはAndroid向けの5ch専ブラで、**iPhone版（iOS版）はありません**（2026年10月時点）。

iPhoneでChMateのように5chを読みたいときは、iOS向けの専ブラ（掲示板専用ブラウザ）を使います。タブ、返信のポップアップ、ID抽出、NGといった、Androidの専ブラでおなじみの機能は、iPhoneの専ブラでも使えます。

この記事では、AndroidからiPhoneに機種変更した人に向けて、iPhoneで同じ感覚で5chを読む方法を紹介します。

## ChMateのiPhone版はある？

ありません。ChMateはAndroid向けに作られた専ブラで、App Storeでは配信されていません。

そのため、AndroidからiPhoneに機種変更したときは、iPhoneで使える別の専ブラに乗り換えることになります。

## iPhoneでChMateのように5chを読むには？

iPhoneでも、App Storeに5chに対応した専ブラがあります。専ブラを選ぶときは、次のような点を見ておくと、ChMateから乗り換えても戸惑いにくくなります。

- **複数のスレをタブで行き来できるか**
- **アンカーやIDを、その場でポップアップで確認できるか**
- **NG機能が充実しているか**（ID、名前、ワード、正規表現など）
- **読んだ位置を覚えて、続きから読めるか**
- **書き込みや、UPLIFT（旧浪人）に対応しているか**
- **5ch以外によく見る掲示板があるなら、それにも対応しているか**

iPhoneで5chを読む方法そのもの（ブラウザと専ブラの違い）は、{{< post "M03" "iPhoneで5chを読む方法" >}}で紹介しています。

## よく使う機能は、iPhoneでも使える？

Androidの専ブラでよく使われる機能は、iPhoneの専ブラでもたいてい使えます。ここでは、掲示板専用ブラウザ「Lichen（ライケン）」を例に紹介します。Lichenは、iPhoneとiPadのための、広告のない5ch専ブラです。

| よく使う機能 | Lichenでは |
|---|---|
| タブで複数のスレを開く | タブで行き来できる。並び替えもできる（{{< post "F07" "タブ" >}}） |
| アンカーのポップアップ・返信ツリー | アンカーをタップすると、返信ツリーをポップアップで表示（{{< post "F12" "ポップアップ" >}}） |
| ID抽出・名前抽出 | IDや名前をタップして、その人の書き込みをまとめて表示（{{< post "F12" "ポップアップ" >}}） |
| NG（ID・名前・ワード・正規表現） | ID、名前、ワード、正規表現、連結NGに対応（{{< post "F14" "NG機能" >}}） |
| 続きから読む | 読んだ位置を覚えていて、新着から読める（{{< post "F05" "続きから読む・更新" >}}） |
| スレ内の検索・抽出 | スレ内検索と、人気・画像・自分のレスなどの抽出（{{< post "F21" "スレ内検索" >}}） |
| オートスクロール・読み上げ | どちらも対応（{{< post "F17" "オートスクロール" >}}） |
| 画像ビューア | サムネイルから全画面で表示、メディア一覧でまとめて見られる（{{< post "F24" "画像・動画" >}}） |
| 次スレ | お気に入りのスレが終わると、次スレを自動で探して引き継ぐ |
| 書き込み・UPLIFT | 書き込みと、UPLIFT（旧浪人）での書き込みに対応（{{< post "F09" "書き込みの基本" >}}、{{< post "F32" "UPLIFT" >}}） |
| テーマ | 4色で配色を変えられる |
| 5ch以外の掲示板 | エッヂ、まちBBS、おーぷん2ちゃんねる、したらばなどに対応（{{< post "F35" "対応している掲示板" >}}） |

## iPhoneならではの操作に慣れよう

iPhoneの専ブラは、iOSの操作に合わせて作られています。Lichenでは、次のような操作を使います。

- **画面の左端から右へスワイプ**：前の画面に戻る
- **スレの画面で、右端から左へスワイプ**：サイドドックを出して、ほかの画面やタブに移る
- **長押し**：レスやスレの操作メニューを出す
- **最下部を引っ張る**：スレを更新する

## ChMateのデータは、iPhoneに引き継げる？

ChMateのお気に入りや履歴、NGの設定を、iPhoneの専ブラにそのまま読み込むことは、基本的にできません。Lichenにも、今のところほかの専ブラのデータを読み込む機能はありません。

よく見る板やスレは、iPhoneの専ブラで開き直して、お気に入りに登録し直すのがいちばん確実です。Lichenでは、板やスレのURLから追加することもできます（{{< post "F34" "板を追加する" >}}）。

NGは、よく使っていたIDやワードを、少しずつ登録し直していくのがおすすめです。
