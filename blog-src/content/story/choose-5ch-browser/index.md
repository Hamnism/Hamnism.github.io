iPhoneで5ch専ブラ（掲示板専用ブラウザ）を選ぶときは、**よく見る掲示板に対応しているか**、**タブ・ポップアップ・NGなどの基本の機能がそろっているか**、**今のiOSに合わせて更新が続いているか**を最初に確かめるのがおすすめです。

そのうえで、書き込み、読みやすさ、広告の有無、データの扱いなど、自分が気になる点で比べていくと、選んだあとで困りにくくなります。

## 専ブラを選ぶときのチェックリスト

| ポイント | 確かめること |
|---|---|
| 対応している掲示板 | 5chだけか。エッヂ、したらば、まちBBSなど、ほかに見る掲示板にも対応しているか |
| 基本の機能 | タブ、アンカーやIDのポップアップ、続きから読む、NG |
| 書き込み | 書き込みに対応しているか。UPLIFT（旧浪人）が使えるか |
| 読みやすさ | 文字の大きさや配色を変えられるか。画面の見やすさ |
| 広告 | 広告が表示されるか |
| 更新状況 | 今のiOSに対応して、更新が続いているか |
| データの扱い | 閲覧履歴などのデータがどこに保存されるか |
| iPad | iPadの画面に合わせた表示に対応しているか |

## 対応している掲示板は？

まず、自分がよく見る掲示板に対応しているかを確かめます。5chだけを読むなら多くの専ブラで足りますが、エッヂ、したらば、まちBBS、おーぷん2ちゃんねるなども見るなら、ひとつのアプリでまとめて読める専ブラのほうが便利です。

読むだけでなく書き込みもしたい掲示板があるなら、その掲示板で書き込みに対応しているかも確かめておきましょう。

## 基本の機能はそろっている？

毎日のように使うなら、次の機能があるかで使い心地が大きく変わります。

- **タブ**：複数のスレを開いたまま行き来できる
- **ポップアップ**：アンカー（>>1など）やIDをタップすると、その場で相手のレスや同じ人の書き込みが見られる
- **続きから読む**：読んだ位置を覚えていて、新しいレスから読める
- **NG**：荒らしや見たくない話題を、IDや言葉で隠せる

## 書き込みはできる？

書き込みもしたい人は、書き込みに対応しているかを確かめます。5chでUPLIFT（旧浪人）を使っている人は、UPLIFTでのログインに対応しているかも大切なポイントです。

名前やメール欄の履歴、書き込みのプレビュー、画像の添付など、書き込みまわりの機能は専ブラによって差があります。

## 読みやすい？

長い時間読むものなので、文字の大きさを変えられるか、配色を変えられるかは意外と大切です。AA（アスキーアート）が崩れずに表示されるかも、気になる人は確かめておきましょう。

## 広告は出る？

専ブラには、広告が表示されるものと、表示されないものがあります。スレを読んでいる途中に広告が入るのが気になる人は、広告の有無を確かめておきましょう。

## 更新は続いている？

専ブラは、iOSのアップデートや、掲示板の仕様変更に合わせて更新が必要なアプリです。長く更新されていない専ブラは、新しいiOSで動かなくなったり、掲示板の変更についていけなくなったりすることがあります。

App Storeの「バージョン履歴」で、最近も更新されているかを確かめておくと安心です。

## データはどこに保存される？

閲覧履歴やお気に入り、書き込みの記録をどう扱っているかは、App Storeの「Appのプライバシー」や、アプリのプライバシーポリシーで確かめられます。

## 迷ったら、まず試してみる

チェックリストで候補をしぼったら、実際に入れて、いつも見ている板やスレを読んでみるのがいちばんです。数日使ってみると、自分に合うかどうかが分かります。

## Lichenの場合

掲示板専用ブラウザ「Lichen（ライケン）」は、iPhoneとiPadのための、広告のない5ch専ブラです。チェックリストのポイントでいうと、次のようになっています。

- **対応している掲示板**：5ちゃんねる、エッヂ、まちBBS、おーぷん2ちゃんねる、したらばなど（{{< post "F35" "対応している掲示板" >}}）
- **基本の機能**：タブ、ポップアップ、続きから読む、NG（正規表現・連結NG）に対応
- **書き込み**：書き込みと、UPLIFT（旧浪人）での書き込みに対応（{{< post "F32" "UPLIFT" >}}）
- **読みやすさ**：文字サイズを4段階で変えられ、テーマで配色も変えられる。AAは専用のフォントで表示
- **広告**：表示されない
- **データの扱い**：閲覧履歴やお気に入りは、すべて端末の中に保存（{{< post "F45" "データとプライバシー" >}}）
- **iPad**：スレ一覧とスレを並べる2カラム表示に対応（{{< post "F44" "iPadと横向き" >}}）
