まちBBSやしたらば掲示板は、Safariなどのブラウザで読めるほか、**対応している専ブラ（掲示板専用ブラウザ）を使えば、5chと一緒にひとつのアプリでまとめて読めます**。

まちBBSは、対応している専ブラならサイトの一覧から選ぶだけで読めます。したらばは、ユーザーごとに掲示板が作られるサービスなので、読みたい掲示板をURLで追加して使うのが一般的です。

## まちBBSとしたらばの違いは？

| | まちBBS | したらば |
|---|---|---|
| どんな掲示板？ | 地域ごとに板が分かれた掲示板 | ユーザーが自分で掲示板を作れるサービス |
| サイトのURL | <https://machi.to/> | <https://jbbs.shitaraba.net/> |
| 専ブラでの読み方 | サイトの一覧から板を選ぶ | 読みたい掲示板をURLで追加する |

したらばは、5chのスレの避難所や、ゲーム・趣味のコミュニティなどでよく使われています。

## ブラウザで読むには？

どちらも、Safariなどのブラウザでサイトを開けば読めます。したらばは、掲示板ごとにURLが分かれているので、スレの中で案内されたリンクや、検索から目当ての掲示板を開きます。

## 専ブラでまとめて読むには？

5chとまちBBS、したらばを行き来するなら、いくつもの掲示板に対応した専ブラを使うと、ひとつのアプリで読めて便利です。続きから読む、タブで行き来する、NGで隠すといった専ブラの機能も、それぞれの掲示板で使えます。

ここでは、掲示板専用ブラウザ「Lichen（ライケン）」を例に紹介します。Lichenは、iPhoneとiPadのための、広告のない5ch専ブラです。

### まちBBSを読む

まちBBSは、Lichenに最初から入っています。

1. Homeの上にある「New Tab」をタップして、「Sites」画面を開きます
2. サイト名の列から「まちBBS」を選びます
3. 地域や板を選んで、スレ一覧から読みたいスレをタップします

LichenのまちBBSは、閲覧のみの対応です。書き込みはできません。

### したらばの掲示板を追加する

したらばは、読みたい掲示板をURLで追加します。

1. Sites画面の右上にある「編集」をタップします
2. 「サイトを追加 (URL から)」をタップします
3. したらばの掲示板のURL（例：`https://jbbs.shitaraba.net/[カテゴリ]/[番号]/`）を貼り付けて、「URL を確認して追加」をタップします
4. 確認が通ったら、「追加」をタップします

追加した掲示板は、Sites画面のサイト名の列に並びます。スレのURLを貼り付けた場合も、そのスレがある掲示板として追加できます。くわしい手順は、{{< post "F34" "板を追加する" >}}で紹介しています。

### スレの中のリンクからしたらばを開く

5chのスレで避難所としてしたらばのリンクが貼られていたときは、そのリンクをタップするだけで開けます。まだ追加していない掲示板なら「したらば板を追加して開きますか？」と表示され、「追加して開く」をタップすると、掲示板を追加してそのスレを新しいタブで開きます。

リンクの扱いは、{{< post "F33" "リンクの扱い" >}}で紹介しています。

### したらばに書き込む

Lichenでは、したらばの掲示板に書き込めます。書き込み方は5chと同じで、スレの下の書き込みバーから書き込みます。

## そのほかの掲示板も読める？

Lichenは、まちBBSとしたらばのほかに、5ちゃんねる、エッヂ、ぷにぷに板、おーぷん2ちゃんねるなどにも対応しています。それぞれで書き込みができるかどうかは、{{< post "F35" "対応している掲示板" >}}の一覧で確認できます。

エッヂの読み方は、{{< post "M06" "エッヂをiPhoneで読む方法" >}}で紹介しています。
