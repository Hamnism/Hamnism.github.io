バージョン 1.3

無限フィード・オンデバイス翻訳・多言語対応／スレ内検索・読み上げ改善・デザイン刷新。

1.3.6 (22)

機能追加とバグの修正、機械学習能力の向上

  • タブのサイドメニューを追加：スマホ表示時にスレを読みながら画面右端から左へスワイプで、タブ・Home・検索・設定にすぐアクセスできる機能を追加しました。
  • Home画面の複数カラム表示：iPad・横向きでフィードを2〜3カラム表示に変更。
  • 翻訳をさらに高速化：いま見ているレスから先に翻訳。
  • 安定性を大幅強化：まれな強制終了や通信が固まる問題を修正、メモリ使用も最適化。
  • データ保存を刷新：今後の更新でも設定やお気に入りが失われにくいように変更。
  • 機械学習能力の向上：Home画面のフィードに表示させるコンテンツの選定アルゴリズムを更新しました。
1.3.5 (21)

修正パッチ

  • UI の微修正をおこないました。
  • バグの修正をおこないました。
1.3.4 (19)

改善

  • フィード画面に不適切画像が表示される場合にモザイク処理をおこなうようにしました。
  • タブのサムネイルを刷新。開いているスレッドの画像からサムネイルを生成するようにし、表示を軽量化しました。画像がないスレッドは板名を表示します。
  • タブの操作を高速化。タブを閉じる時の重さを解消し、Chrome のような縦長カードでサクサク動くようにしました。
  • Home 上部の「開いているタブ」を見やすく。サムネイルを大きくし、余白やレイアウトを整えました。
  • 触覚フィードバックを追加。アップデート案内・新規タブ・フィードからスレを開く・検索など、各所でタップの手応えを返すようにしました。
  • スレ一覧の広告表示を改善。カードデザインに馴染むよう調整しました。

安定性

  • フィード読み込みのリトライを追加。Home の読み込みが一定時間で終わらない場合に、自動でやり直すようにしました。
1.3.3 (17)

修正パッチ

  • フィードのアルゴリズムを調整。フィード画面に表示されるコンテンツのアルゴリズムを修正しました。
  • 表示・操作性の改善。フォントサイズや操作性に関する修正をおこないました。
1.3.2 (14)

新機能

  • Home 画面の刷新。閲覧履歴から推測される関連スレッドや、5ちゃんねる全体での急騰スレッドなどをランダムに表示する機能を追加しました。
  • スレッドのオンデバイス翻訳。スレッドタイトルや内容を、事前にダウンロードした言語パックを用いて翻訳します。
  • UI の他言語対応。iOS の標準設定に応じて UI の言語を変更します。
  • 全体的な UI のアップデート。勢いや発言数などを表示するアイコンをピル型デザインに刷新し、カラーリングも整理しました。

改善・修正

  • レスのコピーを拡張。レス長押しから「ID をコピー」「全てをコピー（レス番号・名前・時刻・ID・本文）」を追加しました。
  • 更新時に新着件数を表示。スレを更新すると「○件の新着」をテロップでお知らせします。
  • 自分のレスに付いた安価（>>）の吹き出しが出ない不具合を修正。
  • タブ一覧の操作性を改善。タブが多い時にスクロールできない問題を解消し、閉じる × を押しやすくしました。
  • 見た目の細部を調整。勢い表示・お気に入り星の配色を統一し、ヘッダーのロゴを刷新しました。
1.3.1 (13)

改善

  • NG（あぼーん）まわりを再構築。ルールの編集・オン/オフがその場で確実に反映されるようになりました。全角/半角・大文字小文字の表記揺れも吸収し、「効く時と効かない時がある」状態を解消しています。
  • NG の管理を快適に。設定の NG 一覧は左スワイプで削除、折りたたまれたレスは長押しで「このレスを表示／ルールを無効化／ルールを編集」を選べるようになりました。
  • 動作の軽量化・省電力化。スレッドの読み込みや自動更新の処理を見直し、CPU 負荷・発熱・バッテリー消費を抑えました（画像キャッシュ強化／重い照合・解析の最適化）。
  • UPLIFT 認証の安定化。セッションの期限切れを検知して、その場で再ログインを案内するようにしました（毎回オン/オフし直す手間を解消）。
1.3 (12)

新機能

  • スレ内検索を追加。🔍 からフリーワードで検索し、該当レスへジャンプ。ヒットしたレスはハイライトされます。
  • 「タイトルと URL をコピー」を追加。スレの共有がワンタップで完結します。

改善

  • 読み上げ・オートスクロールを強化。NG レスや絵文字の読み飛ばし、「次へ/前へ」のズレ修正に加え、再生速度と自動更新の間隔を調整できるようになりました。操作バーは画面上部に移動して本文を邪魔しません。
  • 長文が書きやすく。書き込み欄が広がり、一定行を超えても欄内でスクロールしてカーソルが追従します。
  • URL コピーを通常のスレ URL 形式 (read.cgi) に修正。
  • UI / UX を全体的に刷新。ヘッダーや各種バーのリキッドグラス、配色・余白・影、各種アニメーション、入力バーの自動表示など、細部まで調整して快適にしました。
  • 安定性の向上。YouTube などのリンクをタップした際にアプリが落ちる不具合を修正。通信エラー時のメッセージも分かりやすくしました。
