Lichen

上品な掲示板ブラウザ

Lichen は、5ch・したらば掲示板・おーぷん 2ch・2ch.sc・Next2ch・MMOBBS などの主要な monazilla 互換掲示板を、iPhone / iPad から快適に読めるアプリです。任意の BBSMENU URL を指定して新しい掲示板を追加することもできます。

特長

  • 白基調の落ち着いたデザイン (ダークモード対応)
  • Live モード / Classic モードの 2 つの表示
  • 板単位でスレを保存できるオフラインキャッシュ
  • NG ワード / NG 名前 / NG ID / NG スレタイトル の本格 NG フィルタ
  • スレ読み上げ機能 (画面オフ抑止つき)
  • カメラ / 写真 / 手書き / 音声入力からの投稿
  • UPLIFT (5ch 公式有料プラン) ログインで 5ch の広告を非表示
  • 閲覧履歴・投稿履歴・お気に入りはすべて端末内で完結 (サーバー送信なし)
