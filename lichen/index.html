Lichen

上質な掲示板ブラウザ

Lichen は、5ch・したらば掲示板・おーぷん 2ch・2ch.sc・Next2ch・MMOBBS などの主要な monazilla 互換掲示板を、iPhone / iPad から快適に読めるアプリです。任意の BBSMENU URL を指定して新しい掲示板を追加することもできます。

v1.2 最新アップデート 返信ツリー表示・読み込み高速化・広告の画像表示 ほか →

特長

上質なデザイン

白基調の落ち着いた UI。ダークモードにも対応。

2 つの表示モード

Live モード / Classic モードを切り替えて閲覧。

オフラインキャッシュ

一度読んだスレは圏外でも読み返せる。

本格 NG フィルタ

ワード / 名前 / ID / スレタイトルの 4 系統。

スレ読み上げ

画面オフ抑止つきで“ながら”閲覧。

多彩な投稿手段

カメラ / 写真 / 手書き / 音声入力に対応。

UPLIFT 連携

5ch 公式有料プランのログインで 5ch の広告を非表示。

プライバシー重視

履歴・投稿・お気に入りは端末内で完結。
