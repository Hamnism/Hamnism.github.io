利用規約

この利用規約 (以下「本規約」) は、Hamnism (以下「運営者」) が提供する iOS アプリ「Lichen」(以下「本アプリ」) の利用条件を定めるものです。本アプリを利用される場合、本規約に同意したものとみなします。

1. 本アプリの位置付け

本アプリは 5ちゃんねる (5ch.net) ・したらば掲示板 (shitaraba.net) ・おーぷん 2ちゃんねる (open2ch.net) ・2ch.sc ・Next2ch (next2ch.net) ・MMOBBS (mmobbs.com) 等の monazilla 互換掲示板を閲覧・投稿するための非公式クライアントです。利用者が任意の BBSMENU URL を指定して新しい掲示板を追加することもできます。本アプリは、それぞれの掲示板の運営者とは独立して開発・運営されています。

本アプリは、5ch 運営 (Loki Technology, Inc.) が 2023 年 7 月 11 日に公表した公式声明「全ての 5ch ブラウザは自身の広告 SDK を使用でき、収益を分配する必要はありません」に基づき、独立した広告 SDK を運用しています。

2. 対象年齢

本アプリは 18 歳以上 の利用者を対象としています。掲示板上のコンテンツには、年齢制限のある話題・粗野な表現・刺激的な内容が含まれる場合があるため、18 歳未満の方はご利用いただけません。

  2. 違法・有害・他者の権利を侵害する投稿に起因するトラブル (民事・刑事を含む) は、利用者ご自身の責任で対応するものとします。
  3. 本アプリの利用にあたっては、各掲示板の現行のルール・通達 (例: 5ch の MonaTicket、各種書き込み制限) に従ってください。

4. 禁止事項

本アプリの利用にあたり、以下の行為を禁止します。

  • 法令または公序良俗に違反する行為

  • 誹謗中傷・脅迫・差別的発言・ヘイトスピーチに該当する書き込み
  • 違法な物品・サービスの取引、勧誘、宣伝
  • 各掲示板への過剰なアクセス・自動化された連続投稿等、サーバーに不当な負荷をかける行為
  • 本アプリのリバースエンジニアリング・改変・再配布
  • 本アプリを利用したマルウェア配布、フィッシング、その他不正行為
  • 運営者になりすます行為

4-2. 不適切なコンテンツに対するゼロトレランス方針

本アプリは、不適切なコンテンツや迷惑行為を行う利用者に対して **ゼロトレランス (一切の例外を認めない)** の方針を取ります。

  • 不適切なコンテンツとは、第 4 条「禁止事項」に列挙された内容 (違法・有害・誹謗中傷・ヘイトスピーチ・差別・性的・暴力的な投稿、不正アクセス、嫌がらせ、その他公序良俗に反する一切の表現) を指します。
  • 本アプリの利用者は、これらのコンテンツを投稿してはならず、また、他者のそのような投稿を許容しないことに同意します。

4-2-1. アプリ内で提供する自衛・対処手段

本アプリは、利用者が不快なコンテンツや迷惑な利用者から自身を保護するため、以下の機能を提供します。

  • NG フィルタ: ワード / 名前 / ID / スレタイトル の 4 系統で自動的にコンテンツを非表示にできます (設定 → NG ルール)。
  • 個別投稿の非表示: 任意のレスを長押しして「このレスを非表示」を選ぶと、即座にフィードから除去され、永続的に再表示されません。
  • 利用者のブロック (NG 化): 任意のレスを長押しして「このIDをNG追加」「この名前をNG追加」を選ぶと、その利用者の以後の投稿が自動的に非表示になります。
  • 不適切な投稿の通報: 任意のレスを長押しして「このレスを通報」を選ぶと、該当する掲示板の公式運営通報窓口へリダイレクトします。本アプリは掲示板のコンテンツを物理的に削除する権限を持ちませんが、利用者が直接掲示板運営に通報できる動線を提供します。

4-2-2. 本アプリの立場と外部掲示板の規約遵守

  • 本アプリは外部掲示板を閲覧・投稿するための非公式ブラウザであり、外部掲示板上のコンテンツを作成・管理・削除する権限を持ちません。投稿の削除等は、各掲示板の削除依頼窓口へお願いします。
  • 本アプリを通じた投稿・閲覧にあたっては、各外部掲示板が定める利用規約・ローカルルール・ガイドラインを遵守してください。違反に起因するトラブルは、利用者ご自身の責任で対応するものとします。
  • 本アプリは、上記の自衛機能 (NG / 非表示 / 通報導線) を提供することで、利用者が不快なコンテンツや迷惑な利用者から自身を保護できるようにしています。本アプリ上での表示・非表示の制御は、利用者に委ねられます。

4-2-3. 通報の送り先

不適切なコンテンツ・迷惑行為の通報は、以下のいずれかの方法で行えます。

  • 各レスのコンテキストメニュー「このレスを通報」から、該当掲示板の運営通報窓口へリダイレクト
  • 本アプリ自体に関するお問い合わせは「設定 → お問い合わせ」のフォームから
